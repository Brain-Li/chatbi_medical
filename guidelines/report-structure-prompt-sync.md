# 自定义报告结构：完整提示词更新规则

记录日期：2026-09-21。用于后续需求文档编写。

## 设计结论

采用“生成时同步、章节编辑后按需更新”的方式。基础模式编辑期间不逐字更新完整提示词；在用户需要查看提示词或离开报告结构步骤时更新，避免频繁更新打断输入，并保证后续步骤使用最新内容。

“立即更新”表示章节结构与完整提示词作为同一次生成的结果同步提交，并非在生成完成前展示不完整结果。

## 触发规则

| 用户操作 | 完整提示词行为 | 完成后的界面 |
| --- | --- | --- |
| 在报告需求页首次点击“下一步” | 非空需求直接生成章节结构和完整提示词；成功后一起写入 | 自动切换到“AI 生成的报告结构”页签，仍停留在报告结构步骤 |
| 已有结构，需求已修改，再点击“下一步” | 弹出二次确认，确认后重新生成；成功前不覆盖原内容 | 成功后切到结果页签；取消留在需求页签 |
| 已有结构，需求未修改，再点击“下一步” | 直接复用当前章节和提示词，不重新生成 | 切到现有结果页签，保留手动编辑 |
| 在基础模式点击“重新生成” | 按报告需求重新生成章节结构和完整提示词，替换已有编辑结果 | 展示新结构 |
| 修改章节标题、写作要求，或新增、删除、排序章节 | 仅保存章节编辑，标记提示词需要更新 | 停留在基础模式，不显示加载状态 |
| 有章节变更时切换到高级模式 | 校验章节，按最新章节更新完整提示词 | 先展示“正在更新完整提示词…”；成功后显示可编辑提示词 |
| 在结果页签中，有章节变更时点击“下一步”，或点击顶部后续步骤 | 校验章节，更新完整提示词；成功前不进入后续步骤 | 基础模式显示“正在更新完整提示词，完成后进入下一步…”；成功后进入视觉风格 |
| 章节未变化，或修改后已还原为上次同步内容 | 不重复更新、不展示加载状态 | 直接切换或继续 |

标题与写作要求必填，标题最多20字、写作要求最多2000字，章节数量为1至8个。校验失败时停留在当前步骤，聚焦对应章节并显示字段错误；不启动更新。

章节保持一个连续编辑区域：首个换行前为标题，之后为写作要求。标题始终为黑色粗体（含编辑中、失焦及视觉换行），正文使用常规字重。按 Unicode 字符计数，章节编号不计入标题字数。键盘输入、粘贴及中文输入法提交均检查两段长度；如果本次输入导致任一段超限，拒绝本次输入、保留原内容，并在该章节下方提示对应的字数上限。用户可以删除或替换已有文字；合法编辑后清除超限提示。

只有章节标题或章节完全为空时，编辑区仍保留一行可点击的空白写作要求区域。用户可直接点击该行输入，无需先按回车；也可在标题末尾按回车进入该行，不额外插入一行空正文。空白编辑行不算已填写写作要求，继续时仍按正文必填规则校验。

章节标题前的序号属于可编辑区域，可以用鼠标选中或键盘删除、重写，序号与标题均为黑色粗体。未修改序号时使用默认中文编号并随排序更新；手动修改或删除序号后，保留用户的选择，排序、模式切换和保存后再次编辑均不得自动补回或重置。中文或数字序号（如“一、”“7. ”）不计入标题的 20 字限制，仅有序号不视为填写标题。普通文本按标题内容处理。序号变化纳入章节变更判断，并同步到完整提示词及模板预览，避免额外叠加自动编号。

## 更新中与失败处理

- 更新期间显示加载图标和明确文案；高级模式遮盖旧提示词，避免将旧版本误认为最新版本。
- 暂时禁用章节编辑、提示词编辑、模式与结构方式切换、需求编辑、生成按钮、上一步及下一步；顶部步骤导航不能绕过更新。
- 允许关闭或取消弹窗；关闭后取消本次待更新操作，不自动跳转到后续步骤。
- 更新失败时保留最新章节和上次成功的提示词，提示“更新失败，请重试”，提供“重新更新”按钮。
- 失败时不能继续下一步。重试成功后，若由“下一步”触发，则自动进入视觉风格；若由高级模式触发，则停留在高级模式。
- 更新成功时，同时保存已同步的章节快照与完整提示词，清除待更新状态。

## 高级模式手动编辑

- 高级模式直接编辑完整提示词后，以手动版本为准，点击下一步不重新根据基础章节覆盖它。
- 提示词不能为空且最多4000字；继续时执行校验。
- 高级模式手动编辑后切回基础模式无需确认；完整提示词和基础章节是两种编辑视图，完整提示词的变化不强制反向解析为章节。切换后基础模式继续以章节内容为准，后续按当前模式执行校验和提示词同步。
- “恢复初始版本”恢复当前已同步章节对应的提示词，清除高级模式手动修改标记，不回退基础章节。

## 与报告需求变更的关系

报告需求变更与章节编辑不同：需求修改后必须在报告需求页点击“下一步”生成，或点击基础模式的“重新生成”。仅更新完整提示词不能替代重新生成结构；结果页签中下一步的禁用规则继续生效，但页签不展示“待更新”标签。

报告需求页不再显示单独的“AI 生成报告结构”按钮。该页的“下一步”根据是否已有结构及需求是否改变，执行首次生成、二次确认或复用当前结果，不直接进入视觉风格。顶部后续步骤导航在需求页执行相同流程，不能绕过确认或跳过结果查看。点击“AI 生成的报告结构”页签与下一步复用同一入口逻辑：需求已更改时先二次确认，确认并生成成功后才切换；取消或关闭留在需求页，失败保留旧内容；需求不变时直接查看现有结果。需求为空时点击结果页签也仅标红并聚焦需求框，不弹确认、不切换。首次未生成时结果页签仍不可用。

基础模式的“重新生成”是对当前 AI 结果不满意时的再次尝试：始终使用上次成功生成的原需求（`structureRequest`）重新生成，不读取需求页中尚未提交的草稿，不触发需求变更确认。成功后以原需求、最新结构和完整提示词一起替换当前结果，并将需求输入恢复为本次实际使用的原需求；需求页的“下一步”和结果页签仍按当前草稿执行需求变更确认。

底部“上一步”的返回顺序为：AI 生成的报告结构页签 → 报告需求页签 → 基本信息。结果页签中的基础模式和高级模式均先返回需求页签，保留需求、章节编辑和高级提示词；从需求页签再次点击上一步才返回基本信息。生成中或提示词同步待完成时仍禁用上一步。

## 需求修改后重新生成的二次确认（2026-09-21）

### 触发与判断

- 已成功生成过报告结构，返回报告需求页签修改需求后点击“下一步”或“AI 生成的报告结构”页签，弹出相同确认。即使未手动编辑章节，也需确认，避免误替换已有结果。高级模式切回基础模式不触发该确认。
- 与上次成功生成的需求比较，忽略首尾空白；内部文字、标点或换行变化视为需求修改。修改后完全还原，或只修改首尾空白，不弹确认、不重新生成。
- 首次生成不弹确认。需求为空或全为空白时优先执行空值校验，只标红并聚焦需求框，不能弹确认或发送生成请求。
- 基础模式“重新生成”若使用了修改后的需求，也执行相同确认，避免从另一入口绕过保护；需求未变时主动点击“重新生成”仍执行原有重新生成动作。

### 弹窗文案与操作

- 标题：**确认重新生成报告结构？**
- 正文：**报告需求已更改，重新生成将替换现有章节和提示词。**
- 次按钮：**继续修改**；主按钮：**重新生成**；右上角提供关闭按钮。
- 点击“继续修改”或右上角关闭：仅关闭确认弹窗，保留需求草稿、章节编辑和高级手动提示词，不发起生成；从需求页发起时仍停留需求页。
- 点击“重新生成”：关闭确认弹窗并发起生成，生成中禁用重复操作；不提前清空当前章节或手动提示词。
- 成功：章节、完整提示词及成功需求一起替换，清除待更新、旧错误和高级手动修改标记，打开结果页签，不直接进入视觉风格。
- 失败：保留旧章节、旧提示词与新需求草稿，回到需求页，在需求输入框下方显示具体错误；点击下一步重试时，仍按与上次成功需求的差异进行确认。
- 失败后手动还原为上次成功需求，再点下一步：直接复用旧的有效结果，并清除此前失败状态，不丢失章节及高级手动编辑。
- 未修改需求时直接复用结果，后续从结果页点击下一步仍执行字段校验与章节提示词按需同步，不能以“复用结果”绕过校验。

### 验收场景

1. 首次有效需求直接生成；空需求只标红，不出现确认框。
2. 已生成后修改需求，再点下一步出现上述文案；继续修改或关闭后，新需求及原编辑结果均保留。
3. 确认后成功生成并打开结果页签，原章节/提示词仅在成功后被替换；失败保留原结果并支持重试。
4. 需求不变、仅首尾空白改变、修改后还原时，下一步直接显示原结果，人工章节及高级提示词不丢失。
5. 结果页签、顶部后续步骤和基础模式重新生成不能绕过已修改需求的确认；点击结果页签后取消、关闭、生成失败均不切到旧结果，确认生成成功后才进入结果页签。
6. 高级模式切回基础模式不弹确认，保留两种视图各自的内容；关闭主弹窗后重新新建，不残留重新生成确认状态。

## 最新补充：需求空值与错误反馈

- 移除初始常驻的“请先生成报告结构，再进行下一步”提示。
- 移除生成成功后的“报告结构已生成，可编辑后继续”提示。
- 移除底部“需求已修改，请重新生成报告结构”文案及结果页签的“待更新”标签；保留重新生成二次确认及未更新结构不能进入后续步骤的校验。
- 报告需求未输入或全为空白时，“下一步”可点击；点击后需求输入框显示红色边框及整框浅红底色（#ffece8）并聚焦，停留当前步骤，不新增底部必填文案。输入后清除该错误态并恢复白色底色，但仍须生成成功才能继续。
- 报告需求页的下一步可用于首次生成、需求修改后重新生成及失败重试。只有生成中或提示词同步待完成时禁用并防止重复提交；生成中在下一步按钮显示加载图标。结果页签仍禁止未完成生成或需求待更新时进入视觉风格。
- 需求生成失败的具体原因显示在输入框外侧下方、左对齐，使用红字，并保留输入框红色错误边框；不写入可编辑内容。弹窗底部不再显示同一错误或生成失败摘要。用户开始修改后清除错误文字与边框，底部也不残留失败提示；仍须生成成功才能继续。
- “报告需求”和“AI 生成的报告结构”页签之间使用灰色实心右三角，表示生成方向，不作为可点击控件。

## 验收要点

1. 生成成功后直接切换高级模式，无需重复更新，提示词与章节一致。
2. 编辑任一章节后切换高级模式，看到更新中状态，成功后提示词包含最新章节及顺序。
3. 编辑章节后点击下一步，更新成功前停留；成功后自动进入视觉风格。返回后不再重复更新。
4. 章节校验失败时不更新，字段错误可定位。
5. 更新失败后旧提示词和新章节均保留；重试成功后完成原操作。
6. 高级模式手动提示词不会被下一步操作覆盖。
7. 关闭后重新新建模板，不沿用上一次更新错误或待跳转状态。

## 当前原型实现边界

目前使用本地章节到提示词的编译函数；章节同步阶段约1秒的延迟仅用于演示中间状态。正式接入服务时应由真实请求状态驱动，不能为了展示动画强制等待，也不能在失败时提交旧提示词继续下一步。
